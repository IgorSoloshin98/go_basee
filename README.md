# Go Base Project

## 🛠 Технологии
* Go
* Git & GitHub
* VS Code

## 🚀 Как запустить
1. Склонируйте репозиторий:
   `git clone https://github.com/IgorSoloshin98/go_basee.git`
2. Перейдите в папку проекта:
   `cd go_basee`
3. Запустите программу:
   `go run main.go`

## 📝 Описание
Проект создан для отработки навыков написания кода на Go и работы с системой контроля версий Git.
## 🎯 Цель проекта
Научиться работать с Git и ветками.
